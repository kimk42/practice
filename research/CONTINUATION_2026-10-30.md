# 2026-10-30 재개: PC8 수렴 진단과 버퍼 수용액 후속 검사

기존 계산 원본과 체크포인트를 보존한 상태에서 진행했다. 시작 시 실행
프로세스는 없었고, PC16 상태 파일의 `running` 표시는 전날 기록이었다.
43개 기존 MD 체크포인트, 추가 PC4 6개, citrate 2개의 해시가 모두
일치했다. PC16은 저장된 evaluation002345 좌표에서 재개했다.

## PC8: 수렴 기준 유지, 별도 최적화와 독립 검증

기존 L-BFGS 경로는 RMS 기울기0.00202284 kcal/mol/Å에서 두 번
비정상 종료했다. 동일 좌표를 다시 시작하는 작업은 반복하지 않았다.

보존된 좌표에서 별도 유한차분 계산을 수행했다. SCF 에너지 허용치를
1e-10에서1e-12로 낮춰도 아주 작은 변위에서의 에너지·기울기 불일치가
해결되지 않았다. 출력에 표시되는 `density_conv`를 입력 변수로 쓰는
첫 진단은 설치된 SQM의 namelist에서 거부되어 보존했다. 공개 상류
소스에서 지원하는 `tight_p_conv=1`을 확인하고, 실제 설치 실행 파일의
출력에서도 전자밀도 기준이1e-10으로 바뀌었음을 확인했다. 이 설정도
작은 변위의 에너지 정밀도 문제를 해소하지는 않았다. 상류 소스를
설치 바이너리의 정확한 빌드 소스라고 주장하지 않는다.

에너지 선 탐색 대신 동일한 SQM AM1 기울기를 이용하는 제한된 FIRE
최적화 진단을 별도 폴더에서 수행했다. 최대1000회 평가, 원자당 이동
상한0.001Å, 기존 결합 길이·유한값 검사와 RMS≤0.0005 기준을 유지했다.
39회 평가에서 RMS0.000479842에 도달했다. FIRE의 시간·속도는 최적화
변수이며 실제 분자 동역학 시간이 아니다.

끝점은 다음과 같이 독립적으로 다시 검사했다.

| 검사 | 실제 값 |
|---|---:|
| 원래 SCF 설정의 RMS 기울기 | 0.00047984206 kcal/mol/Å |
| 강화된 전자밀도 수렴 조건 | 0.00047984206 kcal/mol/Å |
| 회전·이동 후 강화된 조건 | 0.00047984804 kcal/mol/Å |
| 원래 좌표계로 되돌린 기울기 RMS 차이 | 1.42×10⁻⁷ kcal/mol/Å |
| 회전 전후 에너지 차이 | −9.31×10⁻⁹ kcal/mol |

끝점의 방향 미분은0.013504 kcal/mol/Å이며, 두 유한차분 간격에서
0.014305/0.013881이었다. 아주 작은 변위에서의 에너지 정밀도 한계는
남아 있으며 Hessian이나 물리적 힘장 정확성을 검증한 것은 아니다.
위 검토를 근거로 **수치 검사 후보의 AM1-BCC/GAFF2 후처리만 허용**했다.
자동적인 기준 완화나 실패 결과의 성공 처리는 없다.

원래 L-BFGS 결과는 `runs/pc-length-sqm-lbfgs-v3/pc8/`, 별도 진단은
`runs/pc8-force-polish-v4/`, 독립 끝점 검사는
`runs/pc8-force-polish-review-v4/`에 있다. 채택 기록은
`runs/pc-length-sqm-reviewed-v4/pc8/completed.json`이며, 검토 파일과
원본 SQM 해시를 다시 검사한 뒤에만 후처리에 사용한다.

## 기판 배치

저밀도 PC8 seed2026도 완료되어 **6/12조건**이 기하 검사를 통과했다.
이번에 독립 재검사한 최소 사슬 간 거리는2.002205Å였다. 기존 PC4
배치 두 개의 전체 분자 박스 구속 편향은 그대로 명시하며, 수정된
생성기 결과와 완전히 동일한 생성 조건이라고 취급하지 않는다.

고밀도6조건은 별도로 진단했다. 각 조건에 거리1.998Å 미만인 사슬 간
원자쌍이1065–1665개 남아 있고, 최단 거리는0.224–0.848Å였다. 따라서
MD로 넘기거나 단순히 성공 기준을 낮추지 않았다. 다음 배치 방법은
사슬 내부 변형을 허용하는 방법 또는 단계적 압축을 별도 프로토콜로
검토해야 한다. 그러한 결과를 기존 고밀도 직접 배치와 동일한 초기화로
표시하지 않는다. 원래 실패한 배치와 저장된 위치는 유지했다.

## 버퍼 후보의 후속 수용액 검사

두 citrate 후보와 두 projected-phosphate 후보는 기존2ps TPR을100ps
연장하고 원래 체크포인트의 좌표·속도를 이어받는 방식이다. 새로
속도를 생성하거나 전하·힘장을 바꾸지 않는다. 결과와 실시간 상태는
각각 `runs/citrate-solution-102ps-v1/`와
`runs/phosphate-solution-102ps-v1/`에 기록한다.

각 완료계에서2001개 저장 프레임의 유한 에너지, 온도, 결합 구조,
산소–물 산소 RDF, 선택한 음이온 산소–Na 최단 거리를 검사한다.
두 시간 창은 중복 프레임을 제외했지만 같은 궤적이므로 독립 반복이
아니다. RDF 산소 배위수는 각 선택 산소 주변의 값이며 분자 전체의
고유한 수화 물 분자 수로 해석하지 않는다.

이 작은 중성 상자의 용질 농도는약61.5mM이다. 실제 cPBSzI 조성이나
최종 pH 종 분포를 재현한 계산이 아니며, 단일 양성자화 상태와 짧은
궤적으로 이온쌍 평형·수화 자유에너지·실험 흡착성을 승인하지 않는다.
정량 결과는 `models/buffer-parameters/{cit3,hcit2,ph1,ph2}-solution-102ps-audit.json`
중 실제로 생성된 완료 보고서에만 기록한다.

네 후보 모두102ps와 분석을 완료했다. 각 연장 구간은100ps이며
기존2ps의 재실행은 없다. 전체 요약은
`models/buffer-parameters/buffer-solution-controls-20261030.json`이다.

| 후보 | 평균 온도(K) | 0.35nm까지 산소당 물O 배위수: 앞/뒤 창 |
|---|---:|---:|
| Citrate³⁻ | 299.655 | 4.234 / 4.195 |
| Hydrogen citrate²⁻, 한 말단 양성자화 | 300.287 | 3.671 / 3.651 |
| H₂PO₄⁻ | 300.384 | 3.852 / 3.861 |
| HPO₄²⁻ | 300.041 | 4.973 / 4.922 |

네 궤적 모두 선택 산소–Na 최단 거리가0.35nm 미만인 저장 프레임은
없었다. 이 부재는 비결합 또는 실제 이온쌍 평형의 증거가 아니다.
시작 배치에서 멀리 놓인 Na의 접근과 긴 시간 규모의 결합·해리 표본이
부족하다. 서로 다른 양성자화 후보의 배위수 차이를 pH에 따른 실제
평균 변화로 해석하지 않는다.

## 보존과 남은 단계

PC16 실행과 PC8 후처리는 기존 자원에서 계속 진행한다. 관리 프로그램만
유휴 상태에서 교체하여 검토된 PC8 경로를 읽도록 했고, 실행 중인 PC16
작업은 중단하지 않았다. PC8 후처리의 원자·결합 그래프는264원자와
279결합으로 원래 정의와 일치함을 중간 확인했다. 전하 후처리 완료나
새 기판 MD 완료는 최종 감사 파일이 생기기 전에는 주장하지 않는다.

전체 코팅/FXII/cPBSzI 계산은 여전히 시작 전이다. 기판의 물성·형태와
완화, 버퍼의 수용액 정확도·미시적 양성자화 상태·조성 선택이 남는다.
실험값을 채워 넣지 않았고, 현재 준비 작업에는 새 사용자 입력이
필수적이지 않다. 상태 JSON뿐 아니라 실제 프로세스와 최신 로그를
함께 확인해야 한다.

새 최적화의 단단한 조화 퍼텐셜 검사를 포함한 회귀 검사22개가
통과했다. 완료된 네 버퍼 궤적의 체크포인트·TPR·궤적 해시도
재확인했다. 기존51개 MD 체크포인트는 여전히 원래 해시와 일치한다.
