# PE 계산 실행기

## 이번 작업의 1–4단계

1. 입력 표준화: 모델·검토된 시작 상태·힘장·SHA-256·온도·시간 간격·위치 억제·실행 길이를 버전이 있는 JSON으로 고정합니다. 임의 명령이나 임의 파일 경로를 브라우저에서 받지 않습니다.
2. 계산 제어: 별도 OpenMM 프로세스를 실행하고 25스텝 경계에서 일시정지·중단을 처리합니다. 두 체크포인트를 번갈아 저장합니다. 중단 후 재시작은 새 작업으로 만들고 원본 작업을 보존합니다. 한 실행 디렉터리의 계산 슬롯은 하나입니다. 일시정지는 CPU를 쉬게 하지만 슬롯은 계속 점유합니다.
3. 화면 연결: 실제 관측값·단계·로그·작업 이력을 표시합니다. 보고서·CSV·출처 데이터를 내려받을 수 있습니다. 미준비 PTFE/PVDF 결정상은 실행할 수 없습니다.
4. 실제 큰 PE 모델 준비: 검증된 100 K, 누적 3 ps 체크포인트에서 아래 유한 길이 프로토콜을 실행합니다. 기술 검사에서 벗어나면 후속 단계를 중단합니다.

## 큰 모델 프로토콜

모델은 관측된 여섯 사슬 피브리노겐 코어, PE C24H50 올리고머 690개, TIP3P 물 165,535개, Na+ 10개, Ca2+ 4개, 총 577,890원자입니다. 긴 αC·기타 결손 말단과 당쇄는 생략했고 중화 이온만 포함합니다. 검증된 벌크 PE 결정이나 무한 표면이 아닙니다.

| 단계 | 설정 | 추가 길이 |
|---|---|---|
| 가열 1 | 120→200 K, 20 K 간격마다 200스텝 | 1 ps |
| 가열 2 | 210→310 K, 10 K 간격마다 100스텝 | 1.1 ps |
| 온도 검사 | 위치 억제 유지, 310 K | 1 ps |
| 위치 억제 해제 | 원래 k의 0.1배 0.25 ps → 0.01배 0.25 ps → 0배 0.5 ps | 1 ps |
| 밀도 추세 검사 | 310 K, 1 bar 등방성 NPT, 2 fs, 25스텝마다 barostat 시도 | 2.5 ps × 3–6블록 |

NVT는 1 fs, LangevinMiddle 마찰 5/ps이며 기존 체크포인트의 RNG를 이어받습니다. 원래 단백질·캡 중원자 및 PE 탄소 위치 억제 k=1,000 kJ/mol/nm²입니다. NPT 전 모든 Cartesian 위치 억제를 0으로 만듭니다. ensemble·시간 간격을 바꿀 때 위치·속도·상자·시계를 보존하고 새 Context를 생성합니다. 이 전환에서 thermostat RNG와 barostat RNG를 다시 시딩하므로 비트 단위 checkpoint 연속 실행으로 주장하지 않습니다. 시드와 전환 이유를 설정·궤적 색인에 기록합니다.

추가 실행 예산은 11.6–19.1 ps입니다. 3블록 이후 기술 검사를 통과하면 일찍 마치며, 최대 6블록 후에도 검사에 실패하면 `needs_review`입니다. **어떤 경우에도 계면 평형이나 생산 계산 준비 완료를 선언하지 않습니다.** CPU 4스레드에서 수 시간이 걸릴 수 있습니다.

## 검사와 해석

각 관측 시 좌표·에너지·온도 유한성, 직교 주기 상자, 제약 오차, Cα 변위, 단백질–PE 중원자 최소 거리를 검사합니다. 600 K 초과·제약 상대 오차 1e-4 초과·Cα RMSD 20 Å 초과·단백질–PE 중원자 거리 0.15 nm 미만이면 중단합니다. 이는 계산 파손을 막는 느슨한 기준이며 단백질의 정상 구조 검증이 아닙니다. 310 K 억제 유지 구간의 마지막 20표본 평균 온도가 목표에서 10 K 넘게 벗어나면 억제 해제에 진입하지 않습니다.

밀도 검사는 최소 3블록을 요구하고, 마지막 두 블록의 평균 전체 밀도 차이 <0.5%, 마지막 블록의 밀도 끝점 변화 <0.5%, 평균 온도 310±5 K, 상대 퍼텐셜 에너지 기울기 절댓값 <0.5%/ps를 모두 요구합니다. **상관된 짧은 표본의 기술 지표**이며 열역학적 수렴 검정이 아닙니다. 밀도는 물·PE·단백질·이온을 모두 합친 전체 혼합계 밀도입니다. NVT의 일정한 밀도는 상자가 고정되기 때문입니다.

끝에서는 NonbondedForce exception을 제외한 심각한 원자 겹침을 확인하고, DCD 원자 수·상자·Cα RMSD와 관측 CSV, 최종 상태의 스텝·시간을 대조합니다. OpenMM DCD의 구간 상대 스텝과 실제 Context 시계 사이 오프셋을 `trajectory-index.json`에 보존합니다.

초기 배치·속도 시드 1개와 짧은 준비 계산으로 흡착량, 리텐션, 결합 자유에너지, 결합 위치, 재료 순위를 추론하지 않습니다. 이를 위해 별도의 더 긴 반복 계산과 실험 조건에 맞춘 모델·염 농도·표면 검증이 필요합니다.

## 실행과 파일

`npm start` → `http://localhost:8000` → 실제 계산 실행과 모니터링. 기본 Python에 과학 패키지가 없다면 `.venv`를 준비하거나 `FIBRINOGEN_PYTHON=/절대경로/venv/bin/python`을 설정합니다. 원본 복원은 README의 Git LFS 절차를 따릅니다.

새 결과는 무시 목록의 `runs/workbench/<job-id>/`에 저장합니다. 설정·관측 JSONL·CSV·체크포인트 색인·체크포인트 2개·System/Integrator 객체·DCD·최종 좌표·검사·HTML 보고서가 포함됩니다. 중단된 작업의 재시작은 검증된 체크포인트의 관측 접두부만 이어받고 새 디렉터리에 씁니다. 원래 작업의 궤적은 그대로 남습니다. CPU/정밀도/OpenMM 버전이 바뀌면 바이너리 체크포인트가 호환되지 않을 수 있습니다.

서버는 토큰과 same-origin POST를 요구하며 숨김 파일·원본 디렉터리의 정적 열람을 차단합니다. 연구자의 로컬 실행 도구이며 인터넷에 공개하는 다중 사용자 서비스로 설계하지 않았습니다. 서버 종료는 계산 취소가 아닙니다. 취소 버튼으로 체크포인트를 남기고 멈추세요.

## 자동 취합

`scripts/finalize_workbench.py --job <id> --wait --archive --push`는 별도 프로세스에서 작업 종료를 기다린 다음, 성공·검토 필요·실패 상태를 그대로 담은 독립 HTML·CSV·JSON을 `artifacts/workbench/preparation/`에 취합합니다. 전체 통합 보고서와 원본 ZIP을 다시 만들고 각 포함 파일의 SHA-256을 확인한 뒤 Git LFS 원본을 갱신합니다. `--push`는 `codex/fibrinogen-pe-md` 브랜치에서만 허용됩니다. 계산과 취합은 분리되어 있어 ZIP 작성이나 업로드 실패가 MD 체크포인트를 지우지 않습니다. 취합 상태는 해당 작업의 `export-status.json`에 기록합니다. 클라우드 환경이 종료되면 자동 취합 프로세스도 중단될 수 있습니다.

검사: Python 단위·API·실제 엔진 전환 검사 25개, Node 검사 3개를 실행했습니다. 별도로 `PYTHONPATH=. .venv/bin/python scripts/check_workbench_controls.py`가 실제 43,288원자 MD를 HTTP API로 제어하고 체크포인트 재시작의 스텝·궤적을 검증합니다. 결과는 `artifacts/workbench/control-integration.json`에 보존합니다. 이 추가 검사는 수 분의 실제 CPU 계산을 수행하므로 기본 CI에는 포함하지 않습니다.

## 완료 상태에서의 NPT 연장

`continue-npt`는 재시작과 다릅니다. 완료되었거나 출력 검증까지 끝난 검토 대상 작업의 마지막 체크포인트에서 **새 유한 길이 계획**을 시작합니다. 원래 단계 인덱스·관측을 새 실행 구간으로 중복 집계하지 않습니다. 위치·속도·RNG·압력 조절기의 상태는 이어받으며, 가열이나 속도 재생성을 하지 않습니다. `continuation-provenance.json`에 출처·체크포인트 SHA·원래 시간과 새 기준 좌표를 기록합니다. 설정의 기본 모델 seed를 다시 적용하지 않으며 실제 RNG는 부모 checkpoint/System/Integrator를 따릅니다.

화면에서 완료된 큰 PE 작업을 선택하고 `NPT 15 ps 연장`을 누르면 310 K, 1 bar, 2 fs, 위치 억제 0의 5 ps × 3블록을 실행합니다. API는 `source_job_id`와 최대 3블록만 받습니다. 검증 파일·최종 상태·중립화 모델·직전 NPT 조건을 확인합니다. 같은 블록의 출력이 없는 실패 작업은 연장 출처로 삼지 않습니다.

250스텝마다 OpenMM의 분자 virial 유한차분 압력을 bar로 기록합니다. API 단위와 상태 복원을 이상기체 단위 검사에서 확인했습니다. 순간 압력 변동은 클 수 있으므로 짧고 상관된 표본의 평균을 평형 압력이나 수렴으로 부르지 않습니다. 밀도 검사에는 마지막 블록의 관측된 상자 크기 변화가 적어도 5번 있어야 한다는 조건을 추가했습니다. 모든 체적 시도가 거부된 평평한 밀도 기록을 검사 통과로 처리하지 않습니다.

`md.solvent_audit`는 물 산소와 비수계 중원자의 주기 거리를 사용해 용질에서 0.8 nm 이상 떨어진 공간의 물 밀도를 추정합니다. 100,000개 균일 공간 표본의 오차는 기하 적분 오차만 나타내며, MD 표본 오차나 평형 검증이 아닙니다. 작은 물 근접성의 공간을 기체 상으로 단정하지 않습니다. 전체 혼합계 밀도와 순수 물 밀도를 직접 비교하지 않습니다.

## 물 단독 구현 대조와 실제 Context 점검

`md.water_control`은 원본 큰 모델의 물 O/H/H 전하·LJ·질량과 PME cutoff·오차·dispersion 조건을 대조한 후, 물 512분자씩 두 개의 독립 초기 배향·속도 시드로 5 ps NVT + 100 ps NPT를 실행합니다. 초기 물 밀도는 0.86 g/cm³입니다. 이 시간은 큰 단백질·PE 모델의 누적 시간에 더하지 않습니다. 액체에 가까운 넓은 밀도 범위, 온도, 체적 변화, 짧은 밀도 추세를 기술적으로 확인할 뿐 폴리머 계면이나 열역학적 수렴을 검증하지 않습니다.

`scripts/continue_after_review.py`는 이전의 검토 대상 NPT 기록을 요약하고 이 대조를 실행합니다. 두 대조가 통과하면 해당 큰 모델 checkpoint에서 같은 조건의 15 ps NPT를 이어갑니다. 실패하면 새 큰 계산을 시작하지 않고 검토 상태로 남깁니다. 이 단계의 원본은 `runs/npt-review01/`, 보고서는 `artifacts/npt-review01/`에 보존합니다. 기존 디렉터리를 덮어쓰는 재실행은 허용하지 않습니다.

추가 연장을 시작할 때 `runtime-conditions.json`에 **실제 Context의** 압력·온도 매개변수, barostat 주기, 위치 억제 수, 적분기 조건을 기록합니다. System의 기본값이 1 bar이더라도 실제 Context가 다르면 진행을 막습니다. 단위 검사에서는 이 둘이 다른 경우를 포함해 검사합니다. 이 검사는 올바른 설정으로 계산하는지 확인하며 실제 평균 압력이 1 bar로 수렴했음을 뜻하지 않습니다.
